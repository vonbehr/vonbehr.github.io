# Python Pipeline Tools

## Render Setup
Überprüfung der Szene und Rendersettings
Rendersettings über Presets anwenden
Benötigter AOVs anlegen
Benötigte Motionblur Overrides anlegen
Custom Renderlayer und Framerange pro Kamera

## Shader Sync
Export und Import von V-Ray Shadern.
Speicherort Projektgebunden oder Universell.
Nur Update von veränderten Shadern.

## Logger
Loggingsystem auf Basis von Sentry.
Zusätzliches Logging von Script Nutzung durch Userals Grundlage für Schulungsbedarf.

## V-Ray Scenes Manager
V-Ray Scenes und alle verknüpften Dateien analysieren, kopieren und Settings umwandeln.
Anwenden auf einzelne Dateien oder alle geladenen V-Ray Scenes

## Lightselect Manager
V-Ray Lichter in Maya Schalten und entsprechende Light Select AOVs anlegen.
Überprüfung auf korrekte Output Namen.

## Save Sun
V-Ray Sun Attribute als JSON Preset abspeichern und laden.

## Groupie
Geometrie halb-automatisch gruppieren. Gruppen-Konfiguration kann über Presets gewählt werden.

## Dataprep Toolbox
Diverse Tools um importierte Daten schnell zu bereinigen und aufzubereiten.
Zum Beispiel:
- Unbekannte Nodes, Legacy Renderlayer und Custom Attributes löschen
- Node Namen bereinigen

## Shader Radial Menü
Umwandeln von Maya Shadern zu V-Ray Shadern mit Presets (Plastik, Glass, Leder, Metallic Lack usw.)
Farbe und Texturen werden beibehalten

Zuweisen und kopieren von Shadern.

## SpecChecker
Automatisierte Erstellung von PDF Dateien aus Renderings
Extraktion des Produktnamens aus den Dateinamen.
Automatischer Upload des fertigen PDFs in den passenden Slack Channel.

## Masks Manager
ObjectIDs und MaterialIDs über Presets zuweisen und benötigte AOVs erstellen.
